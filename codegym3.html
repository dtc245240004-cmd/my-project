Hướng Dẫn Nộp Bài Lên GitHub Repositories

Thực hiện theo 4 bước chuẩn để đẩy mã nguồn bài tập lên GitHub và lấy liên kết nộp bài

Bước 1

Tạo Repository Mới

Truy cập GitHub.com, tạo repository công khai (Public) tên là bai-tap-danh-sach-html.

Mở GitHub Create Repo
Bước 2

Lưu File index.html

Tải file index.html từ Tab 1 về thư mục dự án trên máy tính cá nhân.

Bước 3

Commit & Push Code

Chạy câu lệnh Git để đẩy mã nguồn lên GitHub:

git add .
git commit -m "Done exercise"
git push origin main
Bước 4

Kiểm Tra Link Nộp

Dán URL Repository vào khung kiểm tra bên dưới để xác minh đường dẫn hợp lệ.

Kiểm Tra Đường Dẫn GitHub Repository
