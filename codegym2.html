Thẻ Tiêu Đề (Headings: <h1> đến <h6>)

HTML cung cấp 6 mức tiêu đề từ <h1> (quan trọng nhất, kích thước lớn nhất) đến <h6> (ít quan trọng nhất).

<h1>Tiêu đề cấp 1 (Chính)</h1>
<h2>Tiêu đề cấp 2 (Phụ)</h2>
<h3>Tiêu đề cấp 3 (Mục nhỏ)</h3>
  • Chỉ nên sử dụng 1 thẻ <h1> duy nhất trên mỗi trang web (tốt cho SEO).
  • Sử dụng tiêu đề theo thứ tự thứ bậc hợp lý, không nên nhảy cóc từ <h1> xuống <h4>.

Thẻ Đoạn Văn (<p>)

Thẻ <p> dùng để định dạng một đoạn văn bản (Paragraph). Trình duyệt tự động thêm khoảng trống (margin) trước và sau mỗi thẻ đoạn văn.

<p>Đây là nội dung của một đoạn văn bản.</p>

Mẹo: Không dùng thẻ <p> lồng trong một thẻ <p> khác.

Cấu trúc một trang HTML5 chuẩn 

<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>Trang của tôi</title>
  </head>
  <body>
    <!-- Nội dung bài viết nằm ở đây -->
  </body>
</html>

Hướng dẫn đưa mã nguồn lên GitHub

  1. Tạo một tệp tên index.html trên máy tính và lưu mã HTML bài tập này vào.
  2. Mở terminal/command prompt tại thư mục lưu tệp và chạy các câu lệnh:
    git init
    git add index.html
    git commit -m "Bài tập sử dụng thẻ tiêu đề và đoạn văn"
    git branch -M main
    git remote add origin https://github.com/TênUser/TenRepo.git
    git push -u origin main
  3. Đảm bảo Repository ở chế độ Public (Công khai).
